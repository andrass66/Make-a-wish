# Make a Wish — a little game for Brian 🎂

A dreamy pixel story game. Play in a desktop browser.

**Controls:** `WASD` move · `Space` jump · `Q` interact · `E` talk / next · `Enter` confirm · mouse for mini-games

## Music (add before publishing)
Put these three files in `assets/audio/` (exact names):

| file | used for |
|---|---|
| `in_the_pool.mp3` | opening → June 16 (loops) |
| `i_really_want_to_stay_at_your_house.mp3` | the wake-up twist → montage (loops) |
| `in_the_sea.mp3` | letter → ending (loops) |

If a file is missing the game still runs, just silently.
